# Data Directory

## IMPORTANT DISCLAIMER

The dataset in `raw/reviews.csv` is **SYNTHETIC SAMPLE DATA** generated programmatically
for demonstration and educational purposes only.

**This is NOT real customer review data.**
- It does not represent any real product, company, or customer.
- It was generated using Python's random module with seed 42 for full reproducibility.
- Sentiment labels were assigned deterministically to match the generated review text.
- Evaluation results on this data do NOT establish real-world model performance.

## Dataset Schema

| Column | Type | Description |
|---|---|---|
| review_id | int | Unique row identifier (1-based) |
| product_category | str | One of: Electronics, Books, Clothing, Home & Kitchen, Sports |
| rating | int | 1–5 star rating |
| review_text | str | The review text (synthetic) |
| sentiment | str | Ground-truth label: positive, negative, neutral |
| date | str | Review date in YYYY-MM-DD format (2022–2024) |

## Provenance

- **Source**: Synthetically generated by `data/generate_dataset.py`
- **Seed**: 42 (fully reproducible)
- **Size**: 500+ rows
- **Distribution**: ~50% positive, ~30% negative, ~20% neutral
- **License**: Public domain / educational use

## Processed Data

The `processed/` directory is created at runtime by `run_analysis.py`.
It contains the cleaned dataset used for analysis.
