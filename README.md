# CodeAlpha Task 4 — Sentiment Analysis

**CodeAlpha Data Analytics Internship · Task 4**

An end-to-end sentiment analysis pipeline that classifies product reviews as
**positive**, **negative**, or **neutral** using VADER (default) and an optional
TF-IDF + Logistic Regression classifier.

> ⚠️ **Disclaimer**: The default dataset is **synthetically generated** for
> educational purposes. It does not represent real products, companies, or
> customers. Evaluation results on this data do not establish real-world performance.

## Quick Start

### 1. Clone / open the project

```bash
cd CodeAlpha_Task4_SentimentAnalysis
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Download NLTK data

```bash
python -c "import nltk; nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('averaged_perceptron_tagger'); nltk.download('omw-1.4')"
```

### 5. Generate the dataset

```bash
python data/generate_dataset.py
```

This creates `data/raw/reviews.csv` — a reproducible 520-row synthetic dataset
(seed=42).

### 6. Run the full pipeline

```bash
# VADER (lexicon-based, default, no training required)
python run_analysis.py

# TF-IDF + Logistic Regression (trained classifier)
python run_analysis.py --approach sklearn
```

### 7. Launch the dashboard

```bash
streamlit run app.py
```

### 8. Run the test suite

```bash
pytest tests/ -v
```

## Methodology

### VADER (default)

VADER (Valence Aware Dictionary and sEntiment Reasoner) is a lexicon-based
tool tuned for informal text. It requires no training and runs fully offline.

Score thresholds:
- compound ≥ 0.05 → **positive**
- compound ≤ −0.05 → **negative**
- otherwise → **neutral**

### TF-IDF + Logistic Regression (`--approach sklearn`)

A scikit-learn Pipeline:
1. `TfidfVectorizer` — unigrams + bigrams, max 20,000 features, sublinear TF
2. `LogisticRegression` — C=1.0, balanced class weights, max_iter=1000

Split: 80% train / 20% test, stratified, random_state=42.
The vectoriser is fit **only** on training data (no leakage).

## Known Limitations

| Limitation | Detail |
|-----------|--------|
| Synthetic data | Performance on real reviews will differ |
| Sarcasm | Neither approach detects sarcasm reliably |
| Mixed sentiment | Single-label output for multi-opinion reviews |
| Negation | Simple negation handled; complex chains may fail |
| Language | English only |
| Domain shift | May underperform on domain-specific jargon |
